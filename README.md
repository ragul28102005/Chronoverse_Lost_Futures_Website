# CHRONOVERSE — The Museum of Lost Futures

A cinematic, immersive hackathon website concept built with vanilla HTML, CSS and JavaScript.

## Features
- Cinematic opening portal sequence
- Animated starfield canvas
- Five future timeline cards
- Interactive world modal
- Time Fragment collection system
- Persistent progress with localStorage
- Locked final timeline that unlocks after 4 fragments
- Three selectable endings
- Mouse glow, scroll parallax and reveal animations
- Optional ambient synthesized sound
- Fully responsive layout

## Run
Open `index.html` in a browser.

For deployment, upload the folder to GitHub Pages, Netlify, Vercel, or any static host.

## Hackathon demo flow
1. Click ENTER THE TIMELINE.
2. Open each of the first four worlds.
3. Recover one Time Fragment from each.
4. Watch the fifth world unlock.
5. Enter the final timeline.
6. Scroll to the Chrono Core.
7. Select one of the three endings.
